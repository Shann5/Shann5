# Hi, I'm Shan 👋

I build small, considered tools, mostly local-first, mostly for people who work alongside AI agents.
I write about the building (the decisions, the numbers, what didn't work) at [@shanni_talks](https://x.com/shanni_talks).

### Open source

- **[tab-league](https://github.com/Shann5/tab-league)**: close tabs without losing the thought. Every open Chrome tab
  goes into a local archive, deadline desk and graph, so the tab itself can go. Stdlib Python and plain JavaScript;
  nothing leaves your machine.
- **[true-solar-time-mcp](https://github.com/Shann5/true-solar-time-mcp)**: true solar time (historical DST, longitude,
  equation of time) and BaZi chart casting, as an MCP server, CLI and library.
- **[bazi-open-data](https://github.com/Shann5/bazi-open-data)**: the 30 nayin of BaZi with considered English
  translations. JSON and CSV, CC BY 4.0.

### Products

- **[Docket](https://litchamber.com/agent_sessions/)**: a local dashboard for Claude Code. It sorts your sessions by
  what they need next and puts you back in any of them in one click.
- **[Auspice Oracle](https://auspiceoracle.com)**: a BaZi (Four Pillars) chart with real astronomy under the hood:
  true solar time, honest handling of unknown birth hours, and translations that keep the classical imagery.
  [Free chart calculator](https://auspiceoracle.com/en/chart).
- **[Inkling](https://writeinkling.com)**: an AI journal that writes back. It asks one thoughtful question at a time,
  then helps turn the conversation into a finished piece.

### How I work

Each repo keeps its own notes for agents (`AGENTS.md` for the map, a dated `IDEAS.md` for decisions), so any agent
or person can pick up the work without the conversation that produced it.
[tab-league's README](https://github.com/Shann5/tab-league#keeping-notes-for-your-agents) explains the setup.
